# Remotionで制作したオリジナル作品

各ツールの特徴と作例を紹介するデモ映像です。

- `ReleaseNotes`：公式制作スキルで、リリースノートを場面ごとに見せる映像。
- `VariantFilm`：入力値を変え、一つのReact構成から三つのデザインを展開する映像。
- `WhaleyFilm`：共通のタイムラインで、画面とオリジナル効果音をつなぐ映像。
- `PromoFilm`：31本の作例を使った40秒の紹介動画。[制作資料](PROMO_README.md)も公開しています。

導入と書き出しは[作例の再現手順](../README.md)へ。オリジナル制作コードは本ガイドのMITで公開しています。Remotionの利用には[同プロジェクトのライセンス](https://github.com/remotion-dev/remotion/blob/main/LICENSE.md)が適用されます。
