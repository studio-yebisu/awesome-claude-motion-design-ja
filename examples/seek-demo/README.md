# 時刻指定のオリジナル見本

ブラウザで`index.html`を開くと、時刻を選んで同じ状態へ戻る小さなモーショングラフィックを表示します。外部ライブラリ、画像、モデルAPIへの接続はありません。

`scene.js`の`window.seek(seconds)`が全ての見た目を更新します。制作例のソースとUIを見たい場合は、ガイドのHTTPサーバーから`examples/seek-demo/`を開いてください。

これは時刻指定の設計を説明する独自の見本です。HyperFramesのコンポジション登録やRemotionのフレームAPIを実装したものではなく、MP4のレンダラーも含めていません。
