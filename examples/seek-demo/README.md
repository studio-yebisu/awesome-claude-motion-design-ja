# 時刻指定のオリジナル見本

時刻を選んで同じ状態へ戻る考え方を伝える、小さなモーショングラフィックです。ブラウザで`index.html`を開くだけで動きます。

`scene.js`の`window.seek(seconds)`が全ての見た目を更新します。制作例のソースとUIを見たい場合は、ガイドのHTTPサーバーから`examples/seek-demo/`を開いてください。

独立したHTMLとJavaScriptで、時刻から画面の状態を計算しています。動画にするときは、各時刻のフレームを取得してFFmpeg等で書き出す構成へつなげられます。
