# 出典とライセンス

掲載している作例はClaude Opus 5.5やCodexと制作スキル・ライブラリを用いて制作しています。コードとプレビューを通して制作スタックを選べます。

本ガイドのオリジナル文章、編集データ、制作コード、図版は[MIT License](../LICENSE)で公開しています。使用したライブラリ、フォント、素材、楽曲には、それぞれの利用条件が適用されます。

## ツールを説明するための資料

- モデルと実行環境：[Anthropic](https://www.anthropic.com/claude-opus-5-5)、[Claude Codeのモデル設定](https://code.claude.com/docs/en/model-config)。
- 掲載プロジェクト：各リポジトリのREADME、ライセンス、公式ドキュメント。版と取得日時は[一次資料の記録](../data/verification.json)に掲載しています。
- 制作方法の参考資料：[apimodels.app / claude-opus-5-5-video-prompts](https://github.com/apimodels/claude-opus-5-5-video-prompts)。編集資料は[CC BY 4.0](https://github.com/apimodels/claude-opus-5-5-video-prompts/blob/main/LICENSE)。本ガイドでは独自の日本語説明とCanvas作品を制作し、資料へリンクしています。

各ツールのREADMEとライセンスには、[作例一覧](https://studio-yebisu.github.io/awesome-claude-motion-design-ja/projects.html)から進めます。

## オリジナル作品と使用素材

使用素材と制作環境を作品ごとに記録しています。

- `assets/previews/`：32本の作例のMP4、GIF、ポスター。[制作記録](作例の制作記録.md)に適用スキル、描画・処理、使用版を掲載。
- `examples/`：各作品の制作コードと再現手順。
- Rive作例：公式テスト素材`rocket.riv`（MIT）を使用し、再生・入力・時間の制御を実装。[素材の出典](../examples/runtime/assets/RIVE-ASSET.json)と[MIT全文](../examples/runtime/assets/RIVE-LICENSE.txt)を同梱。
- HyperFrames作例：配布するフォントにそれぞれのOFLを同梱。
- Whaley作例：NumPyで合成したオリジナル効果音を使用。
- `examples/seek-demo/`：時刻を指定する考え方を伝えるオリジナルのHTML・JavaScript。
- `assets/og-card.png`：Studio Yebisuのガイドと実際の作例を紹介する表紙。[生成コード](../scripts/create_og.py)も公開。
- 紹介動画：本ガイドの作例を使ったオリジナル構成。[制作コードと構成表](../examples/remotion/PROMO_README.md)を公開。
- 紹介動画の楽曲：Studio YebisuがSunoで制作・選曲した[Motion Guide — 動く作例から次の一本へ](https://suno.com/song/b4e784fd-9d8f-431d-bb91-75caf386e196)を使用。楽曲の利用はSunoの契約と利用条件に従います。
