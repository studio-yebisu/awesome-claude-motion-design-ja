# 掲載ツールの選び方

**企画・構成・編集・制作：Studio Yebisu**

Studio Yebisuがモーショングラフィックの制作道具を調査し、使いどころに合わせて構成したガイドです。各項目には、この企画のために制作した動く作例、GIF、制作コードを用意しています。

## つくりたい表現から選ぶ

| 分野 | 見るポイント | 主な道具 |
| --- | --- | --- |
| 制作スキル | 構成・デザイン・実装のどこを支えるか | Remotion Skills、Emil Kowalski Skills、motion-graphics-skills、claude-motionなど |
| 動画・書き出し | 制作言語、フレーム管理、音声と書き出し | HyperFrames、Remotion、Motion Canvas、FFmpeg、Mediabunnyなど |
| UI・文字 | 操作感、タイムライン、文字や図形の演出 | Motion、GSAP、Anime.js、canvas-confetti |
| 3D・シェーダー | Reactの有無、カメラ・照明・材質、GPU描画 | Three.js、React Three Fiber、Drei、Cobe、TWGL.js |
| 2D・ベクター | 編集、再生、スプライト、状態に応じた動き | Fabric.js、Rive Runtimes、Lottie Web、PixiJS |
| データ・図解 | データ量、地図、軸や数式、説明の順番 | deck.gl、D3、Manim Community |

まずは[作例一覧](https://studio-yebisu.github.io/awesome-claude-motion-design-ja/projects.html)で動きを見て、近い表現を選びます。次にカードの「使い方・導入のヒント」から、必要な環境と組み合わせを確認できます。

## 制作ルートを決める

短いHTML動画ならHyperFrames、Reactで差し替え可能な動画ならRemotion、操作に反応するWebならMotionやGSAP、数式や仕組みの解説ならManimやMotion Canvasを入口にします。

詳しい構成と導入例は[スタックの組み方](https://studio-yebisu.github.io/awesome-claude-motion-design-ja/guide.html)と[制作スタック](制作スタック.md)へ。HTMLの独立した制作ルートでは、seek(t)で時刻を決め、Playwrightでフレームを取得し、FFmpegで動画へ仕上げる構成も使えます。

## スキルを作品へつなげる

スキルは、表現の規則や制作の進め方をエージェントへ伝えます。ブランドの整理、文字の見せ方、操作感、場面のつながりなど、つくる作品に必要なものを選びます。

本ガイドでは、Studio Yebisuの企画と制作ディレクションのもと、Claude Opus 5.5とCodexを使ってスキルを実装へ落とし込みました。31本のオリジナル作例と40秒の紹介動画を制作し、コードの実行、レンダリング、編集、視聴まで進めています。

- [作例の制作記録](作例の制作記録.md)：適用したスキル、使用版、素材、各作例のコード。
- [制作コードと再現手順](../examples/README.md)：ブラウザ作例と専用エンジンでの制作。
- [紹介動画の制作](../examples/remotion/PROMO_README.md)：40秒の構成、Remotionの実装、Sunoの楽曲。

## 導入前に見る利用条件

掲載する31件は、OSSとして分類した26件、独自ライセンス2件、独立したルートLICENSEを確認できなかった2件、参考資料1件です。作例一覧では、利用条件でも絞り込めます。

Remotion・GSAPの独自条件、FFmpegのビルド条件、RiveやLottieで使う素材、スキルの各パックなど、作品に組み込む範囲の条件を確認します。[出典とライセンス](出典とライセンス.md)に主なリンクをまとめています。

## 資料と制作版の記録

ツールの説明には、各プロジェクトのREADME、ライセンス、公式ドキュメントを使っています。Claude Codeのモデル指定は[Anthropicのモデル設定ガイド](https://code.claude.com/docs/en/model-config)、HyperFramesとRemotionの制作方法はそれぞれの公式資料へつないでいます。

- [data/verification.json](../data/verification.json)：2026年10月12日取得のリポジトリ情報、commit、README、star数。

- [data/skill-inputs.json](../data/skill-inputs.json)：制作に適用したスキルの版。
- [data/preview-production.json](../data/preview-production.json)：作例の使用版、実出力、ファイル情報。

動く作例は2026年10月13日制作。使用版と実行工程を作品ごとに記録しています。新しい版で再制作する場合は、各ツールの現在のAPIと導入条件に合わせてください。
