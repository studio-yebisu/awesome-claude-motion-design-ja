# URLを共有したときのカード

トップ、作例一覧、スタックの組み方の3ページに、ページごとのタイトル・説明・canonical URLを静的HTMLで設定している。JavaScriptの実行を必要としない。

共通の表紙は `assets/og-card-motion-v3.png`、1200×630のPNG。6種類の実際の作例、31本のオリジナル作例、Studio Yebisuの企画・制作クレジットを掲載している。

Open Graphの `og:title`、`og:type`、`og:url`、`og:image`、説明、サイト名、locale、画像の寸法・形式・ALTを設定。X向けには `twitter:card=summary_large_image` とタイトル・説明・画像・ALTを明示している。設定項目は [Open Graphの仕様](https://ogp.me/) に基づく。

```text
python scripts/create_og.py
python scripts/build_site.py
python scripts/check_site.py
```

3ページの設定と画像の寸法を検査し、公開後はTwitterbot User-Agentでページと画像の200応答・Content-Typeを確認する。サービス側の既存キャッシュと実際のカード表示は、公開HTMLの検査と別に扱う。
