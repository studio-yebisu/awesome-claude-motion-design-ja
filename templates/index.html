AN ORIGINAL PROJECT BY STUDIO YEBISU

Studio Yebisuのオリジナル制作ガイド

「道具の使いどころを、実際の動きで伝えたい」というアイデアから生まれた企画です。Studio Yebisuが構成・選定・編集・制作を進め、各項目の作例と40秒の紹介動画を、このガイドのために制作しました。

スキルを使い、作品として仕上げる。

Claude Opus 5.5やCodexを制作に活用し、スキルの規則を表現に落とし込み、コードを実行して映像へ。31本それぞれに、動く作例、GIF、制作コードを公開しています。気に入った動きから、自分の制作へつなげてください。
